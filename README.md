Представницький сайт-візитівка для **Адвокатського об'єднання "Громада і Закон"** з кастомною адмінкою на хмарних базах. 

## Gromada Project

```
React Next JS
Node 22+
SCSS / Tailwind CSS
Firebase Realtime Database
Vercel Deploy
```

### Особливості локального запуску

Створити файл `.env.local` та записати туди ключі доступу до бази. Ключі в налаштуваннях аккаунту або на Google Drive.

```
FIREBASE_PROJECT_ID
FIREBASE_CLIENT_EMAIL
FIREBASE_DATABASE_URL
FIREBASE_PRIVATE_KEY
```
